# Evidencias CI/CD

Esta carpeta identifica las evidencias académicas que deben conservarse sin secretos:

- Pull Request con `Quality Gate`, `Expo Doctor` y `SDD Traceability Gate`.
- Resultados de lint, typecheck, tests y coverage.
- Ejecuciones de CodeQL, npm audit, Dependency Review y Gitleaks.
- Configuración y ejecución manual de Preview EAS.
- ID del build EAS y artefacto APK de preview.
- Primer AAB de Production, versionCode y commit SHA.
- Configuración de branch protection.
- Validación de privacidad y estrategia `MANUAL_GOOGLE_PLAY_UPLOAD`.

No guardar tokens, JWT, credenciales ni capturas que los contengan.
